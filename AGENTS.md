# Проверки
- По умолчанию сборка и тесты — без UI: `powershell -NoProfile -File Validation/Check.ps1`.
- Все временные файлы проверок (логи, снимки, результаты, сборки) — только в `.test-artifacts/`. Периодически удаляй там файлы старше 3 дней, проверив, что пути остаются внутри каталога и не проходят через ссылки; исходники и постоянные ресурсы не удаляй.
- Реальные UI-тесты (мышь, клавиатура, окна, RDP) — только с явного согласия пользователя, после предупреждения, в видимом интерактивном режиме с немедленной остановкой. Фоновый запуск и вмешательство в рабочий стол без предупреждения запрещены.
- Перед отдельным UI-тестом или серией предупреди пользователя и получи согласие. Одно явное согласие на серию разрешает все запуски в согласованном лимите, включая повторные запуски после исправлений; перед каждым тестом серии повторное подтверждение не требуется. При отмене немедленно остановись.
- В тестовой серии сворачивай RDP после каждого запуска независимо от результата. После серии оставляй ShowroomBot открытым для Telegram-команд; штатное использование не должно сворачивать RDP.
- После проверки кратко сообщай результат и путь к артефактам.
- Тесты — Debug. После согласия на UI: `Start-Process <Debug/ShowroomBot.exe> -ArgumentList '--scenario 3 --run' -Wait -PassThru` (видимый запуск, не Hidden). Коды: 0 успех, 1 ошибка, 2 отмена; отчёт `.test-artifacts/cli-*/result.json` относительно рабочего каталога. Перед запуском закрой текущий экземпляр; параллельные запрещены. Без `--run` параметр `--scenario` только выбирает сценарий.
